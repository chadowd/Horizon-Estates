                        HORIZON ESTATES
                        _______________

                            Site moderne et responsive d'immobilier fait avec HTML , CSS et Javascript
___________________________________________________________________________

  Horizon Estates est un site web immobilier moderne conçu pour offrir une expérience épurée,élégante et responsive aux utilisateurs intéressés par les services et les propriétes immobilieres.
  le projet met l'accent sur une interface utilisateur moderne , des mises en page adaptatives , les animations avec des fonctionnalités développées en Javascript
